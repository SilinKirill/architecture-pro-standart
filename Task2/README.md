## Артефакты

## Описание

В таблице собраны архитектурно-значимые требования для MVP цифровизации депозитных и кредитных заявок.

Требования сгруппированы по модели FURPS+:

- `F` — функциональные требования;
- `U` — удобство использования;
- `R` — надёжность;
- `P` — производительность;
- `S` — поддерживаемость;
- `+R` — ограничения.
