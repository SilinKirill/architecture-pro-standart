## Карта IT-ландшафта

Карта построена в формате матрицы:

- строки — подразделения организационной структуры банка;
- колонки — бизнес-возможности второго уровня из Business Capability Map;
- ячейки — системы, приложения и ручные инструменты, которые используются сейчас.

Цвета на карте:

- синий — ИТ-система;
- оранжевый — ручной процесс;
- красная рамка — проблемная интеграция или ограничение;
- серый — возможность сейчас не используется или недоступна;
- пунктир — внешняя система.

## Что показано на схеме интеграций

### Депозитный процесс

Сейчас клиент открывает депозит через отделение. Фронт-офис работает с АБС, а ставка рассчитывается через депозитный бэк-офис.

Для специальных ставок депозитный бэк-офис запрашивает данные у кредитного бэк-офиса.

Расчёт ставки выполняется вручную через Excel и e-mail.

Если клиент предварительно звонил в кол-центр, обращение создаётся в системе кол-центра и передаётся в АБС.

После фиксации ставки АБС отправляет клиенту SMS через SMS-шлюз.

### Кредитный процесс

Кредитная заявка создаётся фронт-офисом в АБС.

Раз в сутки заявка передаётся в Кредитный конвейер.

Кредитный конвейер вызывает систему скоринга по REST API.

При расчёте скоринга система онлайн запрашивает данные в БКИ.

Внутренние данные банка для скоринга обновляются пакетно, раз в сутки.

Финальное решение по заявке возвращается в АБС также раз в сутки.

## Основные проблемы As-Is

1. Депозитная ставка рассчитывается вручную в Excel.
2. Согласования идут через e-mail.
3. Для открытия депозита обязательно участвует бэк-офис.
4. Интернет-банк интегрирован с АБС напрямую через базу данных.
5. В кредитном процессе есть batch-интеграции раз в сутки.
6. Сайт сейчас не участвует в подаче заявок.
