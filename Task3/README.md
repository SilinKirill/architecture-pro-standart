## Описание

В ADR описана концептуальная архитектура MVP открытия депозитов онлайн.

Решение покрывает:

- подачу заявки с сайта;
- подачу заявки из интернет-банка;
- обработку заявки в АБС;
- централизованную работу со ставками;
- интеграции сайта, интернет-банка, АБС, системы кол-центра и SMS-шлюза.
