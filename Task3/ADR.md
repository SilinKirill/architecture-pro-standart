### **Решение**

Для MVP вводится новый **сервис депозитных заявок** между цифровыми каналами и АБС.

Сайт и интернет-банк обращаются к сервису депозитных заявок, а не напрямую к АБС. Сервис принимает заявки, хранит статусы, отдаёт ставки и условия в цифровые каналы, передаёт заявки в АБС и отправляет СМС через SMS-шлюз.

АБС остаётся системой учёта. Бэк-офис продолжает работать в АБС: подтверждает ставку, условия и открытие депозита. Ставки и условия централизуются в АБС, чтобы уйти от XLS-файлов как основного источника.

Интеграция с АБС выполняется через отдельный модуль/API с retry и идемпотентностью. Для отслеживания заявки между системами используется единый идентификатор заявки.

Интернет-банк дорабатывается минимально: добавляется сценарий подачи депозитной заявки, а основная бизнес-логика выносится в сервис депозитных заявок. Это снижает зависимость от подрядчика ядра интернет-банка.

Основные интеграции:

| Интеграция                                    | Назначение                                            |
|:----------------------------------------------|:------------------------------------------------------|
| Сайт → сервис депозитных заявок               | Заявка нового клиента и получение ставок.             |
| Интернет-банк → сервис депозитных заявок      | Заявка действующего клиента и персональные ставки.    |
| Сервис депозитных заявок → система кол-центра | Передача заявки с сайта для звонка клиенту.           |
| Сервис депозитных заявок ↔ АБС                | API-интеграция: заявки, статусы и ставки              |
| Сервис депозитных заявок → SMS-шлюз           | СМС-коды и уведомления клиенту.                       |
| Депозитный бэк-офис → АБС                     | Подтверждение условий и открытие депозита.            |
| Кредитный бэк-офис → АБС                      | Передача данных риска для специальных ставок.         |

### **Альтернативы**

| Альтернатива                                    | Причина отказа                                                                       |
|:------------------------------------------------|:-------------------------------------------------------------------------------------|
| Прямая интеграция сайта и интернет-банка с АБС  | АБС перегружена и масштабируется только вертикально.                                 |
| Реализовать бизнес-логику в ядре интернет-банка | Потребуются доработки подрядчика и усилится зависимость от монолита.                 |
| Оставить ставки в XLS-файлах                    | Сохраняется ручной процесс и нет единого источника ставок.                           |
| Сразу использовать Kafka                        | Интернет-банк сейчас несовместим с Kafka; для MVP достаточно API-интеграции с retry. |

**Недостатки, ограничения, риски**

1. В MVP депозит не открывается полностью автоматически: условия подтверждает бэк-офис.
2. Новые клиенты всё ещё должны проходить идентификацию в отделении.
3. АБС остаётся узким местом при росте нагрузки.
4. Требуются доработки АБС для заявок, ставок, статусов и интеграции.
5. Нужно контролировать актуальность ставок между АБС и цифровыми каналами.
6. Сбой SMS-шлюза может задержать подтверждение операции или уведомление.
7. При ошибках интеграции с АБС нужно исключить повторное создание заявок.
